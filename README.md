# 🚀 NeuroQuest – Gamified AI Learning Platform

NeuroQuest is a futuristic landing page concept for an AI-powered learning and productivity platform. Inspired by modern gaming interfaces, the entire user journey is transformed into an interactive quest where users earn XP, unlock achievements, collect rewards, and progress through levels simply by exploring the page.

🔗 Live Demo: [https://your-live-link.com](https://garimadixit80.github.io/Landing-page/)

## ✨ Features

### 🎮 Gamification System

* Real-time XP Progress Bar
* Dynamic Level Tracker
* Coin Collection Counter
* Achievement Unlock Notifications
* Scroll-Based XP Rewards

### 🏆 Interactive Components

* Quest Cards with Reward Mechanics
* Spin-the-Wheel Mini Game
* Live Leaderboard
* Achievement Badge System
* Animated Reward Popups

### 🌌 Visual Experience

* Deep Space Inspired UI
* Interactive Particle Field Hero Section
* Neon Cyberpunk Color Palette
* Smooth Scroll Animations
* Glassmorphism Effects
* Responsive Design

## 🎯 Purpose

This project demonstrates how gamification can be integrated into modern web experiences to increase engagement, retention, and user interaction. It combines creative UI/UX design with advanced frontend animations and state-driven interactions.

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)

## 📸 Highlights

* XP increases as users scroll through content.
* Achievement badges unlock at milestone checkpoints.
* Interactive quest cards reward user actions.
* Spin-the-Wheel game provides bonus rewards.
* Leaderboard updates dynamically based on earned XP.
